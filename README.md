# Taper Type — SHAKURA Perspective

Serve this folder with any static web server and open its URL in a modern browser. Anton is included locally; the page needs an internet connection for the OpenType outline parser and the DM Sans/DM Mono interface fonts. It creates flattened SVG paths in the browser without a backend.

Use **Download SVG** to save the result. **Copy SVG for Figma** puts the flattened vector on the clipboard where supported, with SVG markup as a fallback. Direct insertion into a Figma document is only available from the original Figma plugin.
